# Security

Report a security or privacy problem with GitHub private vulnerability reporting: open the
**Security** tab of this repository and click **Report a vulnerability**. Do not open a
public issue, and do not attach real patient data.

Privacy model: the audio, the raw transcript and the table of removed personal details stay
on the computer. Only clean text that a person approved, or that shows no blocking warning
sign, goes to the LLM provider; the removal can miss a detail.
